# Jijau Computers - WordPress Installation & Setup Guide

This guide walks you through installing and configuring the **Jijau Computers WordPress Theme & Core Plugin** on any fresh WordPress installation (including Hostinger, Cloudways, cPanel, or Localhost).

---

## 📦 What's Included in the Package:

1. **WordPress Theme ZIP**: `wordpress-theme/jijau-computers.zip`
2. **Core Plugin ZIP**: `wordpress-plugin/jijau-core.zip`
3. **Demo Data**: `wordpress-demo/sample-data.json` & `wordpress-demo/jijau-computers-demo.xml`
4. **Documentation**: `wordpress-docs/`

---

## 🚀 Quick 3-Step Installation:

### Step 1: Install & Activate Theme
1. Open your WordPress Admin Dashboard (`/wp-admin`).
2. Go to **Appearance > Themes**.
3. Click **Add New Theme > Upload Theme**.
4. Choose [`wordpress-theme/jijau-computers.zip`](file:///Users/anantwagh/Antigravity%20Projects/jijaucomputers/wordpress-theme/jijau-computers.zip) and click **Install Now**.
5. Click **Activate**.

### Step 2: Install & Activate Core Plugin
1. Go to **Plugins > Add New Plugin**.
2. Click **Upload Plugin**.
3. Choose [`wordpress-plugin/jijau-core.zip`](file:///Users/anantwagh/Antigravity%20Projects/jijaucomputers/wordpress-plugin/jijau-core.zip) and click **Install Now**.
4. Click **Activate Plugin**.

### Step 3: Populate Demo Data
- Upon activating the `Jijau Computers Core` plugin, the default 25+ hardware products, 15 categories, 18 brands, 3 hero banners, coupons, and store settings are automatically seeded into your database!
- If you ever wish to reset or re-seed the dataset, simply navigate to **Jijau Admin Panel > Settings** and click **"Seed Demo Catalog"**.
